# Zeeho Unlocker

用于测试 ZEEHO APP（`com.cfmoto`）功能的 LSPosed 模块。

启用后可解锁 App 内按车型灰度关闭的入口（孪生仪表、主题商城、骑行数据等），
调整深色模式与状态栏配色，自定义仪表壁纸 / 车辆立绘 / 2D·3D 车模 / 充电动画，
并在小米澎湃 OS 上把充电状态投射为超级岛或实时活动。

## 使用

1. 设备需已安装 LSPosed（本模块要求 API 100 以上）；
2. 安装本模块并在 LSPosed 中启用，作用域勾选 `com.cfmoto`；
   充电超级岛 / 实时活动另需 `com.android.systemui`；
3. 重启 ZEEHO APP 后生效。设置入口：模块桌面图标，或 APP 内「车辆服务」页的设置行。

免 root 场景可通过 NPatch 打包后使用（仅 `com.cfmoto` 作用域）。

## 说明

- 仅供功能验证使用，不保证所有车机/车型可用；
- 修改 App 行为的开关是否真实生效取决于车辆控制器与服务端下发，部分项目仅界面可见；
- 本仓库只发布 APK 与更新日志，不提供源码。
